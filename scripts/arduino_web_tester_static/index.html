PID Autotune (Relay Feedback)

Astrom-Hagglund relay-feedback identification -- the describing-function method behind essentially every commercial auto-tuning PID controller. Toggles raw PWM between +/-relay around the setpoint to induce a limit-cycle oscillation, measures its period/amplitude to get the ultimate gain Ku directly (no process model needed), then derives gains via two rules: Ziegler-Nichols (classic, more aggressive) and Tyreus-Luyben (detuned specifically for relay-identified Ku/Pu -- the safer default on real hardware). Runs open-loop with PID disabled; both motors spin together the whole time, so give the robot room to move or put it up on a stand.

ROS2 Mode

Launches the real ros2_control stack (controller_manager, diff_drive_controller, etc.) so the board is driven the way it normally runs -- not via this tool's direct serial protocol. Launching automatically disconnects the Connection panel above (ros2_control needs exclusive access to the Arduino); while ROS2 mode is running, Connect is blocked here.
